# Tsuper Items

ม็อดอาวุธสำหรับ Terraria / tModLoader

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3054910532)

repository นี้เปิด source code บางส่วนของ Tsuper Items ให้ศึกษาวิธีทำม็อด
และนำโค้ดไปดัดแปลงเพื่อพัฒนาต่อได้ ตามเงื่อนไขใน [ประกาศสิทธิ์](COPYRIGHT.md)

งาน art ส่วนใหญ่เป็นงานที่ผู้สร้าง Tsuper Items (SuperItem) สร้างขึ้นเอง
ธีมของงานบางส่วนได้รับแรงบันดาลใจจาก Terraria และม็อดอื่น โดยไม่ได้คัดลอกผลงานต้นทางโดยตรง

**งาน art ทั้งหมดเป็นสิทธิ์ของผู้สร้างสรรค์ผลงานแต่ละราย และยังสงวนลิขสิทธิ์**
การอนุญาตให้ใช้โค้ดไม่รวมภาพอาวุธ sprite texture icon ภาพเอฟเฟกต์ แอนิเมชัน
หรือไฟล์งานศิลป์อื่น ๆ ของม็อด รวมถึงงานที่แสดงใน Workshop
หากต้องการนำงาน art ไปใช้ ต้องได้รับอนุญาตจากผู้ถือสิทธิ์ของผลงานนั้นก่อน

## Source code สำหรับศึกษา

ดูไฟล์และคำอธิบายใน [Source/README.md](Source/README.md)
มีซอร์สจริง 8 ไฟล์ที่คัดจากรุ่น 0.6.2 ครอบคลุม:

- การตั้งค่าอาวุธ การยิง projectile และสูตรคราฟต์
- กฎของสกิล เช่น คูลดาวน์ ความเร็ว และการคำนวณความเสียหาย
- จังหวะดาบและ geometry ที่ใช้ร่วมกันระหว่างภาพกับการชน
- easing สำหรับแอนิเมชัน การตั้งค่า client/server และกล้องสั่น

นี่เป็นซอร์สบางส่วนสำหรับอ่านและประยุกต์ใช้ ยังมี dependency ของม็อดที่ไม่ได้รวมมา
จึงไม่สามารถ build Tsuper Items ทั้งม็อดจาก repository นี้ได้
ไฟล์ม็อดสำหรับเล่นอยู่ที่ Steam Workshop ตามลิงก์ด้านบน

## การใช้และเครดิต

การอนุญาตให้ศึกษาและพัฒนาต่อครอบคลุมเฉพาะไฟล์ `.cs` ที่เผยแพร่ใน `Source/`
เมื่อนำโค้ดไปใช้ ให้คงประกาศสิทธิ์และระบุเครดิต Tsuper Items / SuperItem
ในสำเนาหรือโค้ดที่ดัดแปลงตาม [COPYRIGHT.md](COPYRIGHT.md)
ซอร์สที่ไม่ได้เผยแพร่และงาน art ไม่อยู่ในการอนุญาตนี้

หากต้องการใช้ส่วนอื่น กรุณาขออนุญาตผู้ถือสิทธิ์ก่อน
โดยเปิด issue แจ้งส่วนที่ต้องการใช้และลักษณะการใช้งาน

Terraria, tModLoader และผลงานของม็อดอื่นยังเป็นของผู้สร้างแต่ละราย
